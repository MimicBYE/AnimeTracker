# Anime Tracker 1.0

Трекер аниме с бумажным оформлением для Windows и macOS. Один релиз содержит сборки обеих платформ и исходный код.

## Возможности

- Библиотека с пятью статусами, просмотренными сериями, оценками и заметками.
- Поиск Shikimori на русском, английском и японском, обложки, жанры и количество серий.
- Необязательный виджет с кнопкой +1, тремя вариантами оформления и закреплением аниме. Отключение сохраняется после перезапуска.
- Общие настройки: виджет, оформление, автозапуск и резервные копии.
- Календарь выпусков, продолжения, общий и личный топы, сравнение аниме и экспорт в PNG.
- Подбор на вечер из планов, топа Shikimori или очереди; скрытие неинтересных рекомендаций и проверка предыдущих сезонов.
- XML/GZIP-импорт MyAnimeList со статусами, оценками и прогрессом.
- Арки и филлеры: встроенный справочник и собственные правки.
- Локальное хранение, резервная копия ZIP и перенос папки данных с Windows на Mac.

## Скачать и запустить

- **Windows 10/11 x64:** `AnimeTracker-1.0-windows-x64.zip`. Распакуйте весь архив и запустите `AnimeTracker.exe`. Нужен .NET Framework 4.8+.
- **macOS 14+ / Apple Silicon:** `AnimeTracker-1.0-macos-arm64.zip`. Распакуйте архив и переместите `Anime Tracker.app` в Applications. .NET включён.
- **Исходники:** `AnimeTracker-1.0-source.zip`.

Контрольные суммы всех трёх архивов находятся в `SHA256SUMS.txt`. Личная библиотека и пользовательские настройки в архивы не включены. При обновлении сохраните свою папку данных.

## Ограничения

Windows EXE не подписан. Mac-приложение не имеет Developer ID и нотарификации Apple; Gatekeeper может блокировать запуск. Нативный запуск на Mac, Show Desktop/Spaces и автозапуск ещё требуют проверки на реальном Mac.

Каталог и расписание зависят от внешних API. Время календаря — московское UTC+3, справочник арок покрывает отдельные тайтлы. Синхронизации личного прогресса с аккаунтами MAL/Shikimori нет. Лицензия собственного кода пока не выбрана.
