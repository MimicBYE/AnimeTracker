# Anime Tracker 1.0.0

Первый подготовленный релиз для Windows x64. Интерфейс на русском, переносимая версия без установщика.

## Основные возможности

- Библиотека со статусами, сериями, оценками и заметками; поиск и фильтры по нескольким жанрам.
- Поиск Shikimori с обложками и названиями на нескольких языках; обновление серий и календарь выпусков.
- Виджет с +1, закреплением на рабочем столе, тремя вариантами оформления и меню в трее.
- Очередь просмотра с изменением порядка и отдельным источником в подборе «На вечер».
- Постоянное скрытие неинтересных рекомендаций с возможностью возврата.
- Подбор из планов или первых 200 позиций топа Shikimori; проверка предыдущих сезонов для продолжений.
- Общий и личный топы, сравнение равных оценок и экспорт подборки в PNG.
- XML/GZIP-импорт MyAnimeList с предварительным просмотром и резервной копией.
- Ручные арки и встроенный справочник арок/филлеров с указанием источников.

## Установка и обновление

Распакуйте `AnimeTracker-1.0.0-windows-x64.zip` в папку с правом записи и запустите `AnimeTracker.exe`. Требуется .NET Framework 4.8 или новее.

При обновлении завершите приложение через трей и сохраните свою папку `data`. Архив не содержит библиотеку, личные настройки, обложки или импортированные списки.

## Известные ограничения

- Только Windows; закрепление виджета зависит от Explorer.
- EXE не подписан цифровым сертификатом.
- Каталог и расписание требуют доступности внешних API; дата календаря — ближайший известный выпуск, время московское.
- Топ для вечернего подбора ограничен первыми 200 позициями; непроверенные зависимости сезонов исключаются.
- Справочник арок частичный и обновляется вместе со сборкой, а не в реальном времени.
- Нет синхронизации пользовательского прогресса с аккаунтами MAL/Shikimori.

Контрольные суммы ZIP-файлов приведены в `SHA256SUMS.txt` рядом с архивами.
