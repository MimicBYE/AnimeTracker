Anime Tracker 1.0 — быстрый старт

1. Распакуйте весь архив в отдельную папку с правом записи.
2. Запустите AnimeTracker.exe. Нужна 64-битная Windows 10/11 и .NET Framework 4.8+.
3. Двойной клик по бумажному виджету или значку в трее открывает библиотеку.
4. Нажмите «Добавить». Для переноса списка MAL откройте ⚙ Настройки → Данные и резервные копии → Импорт XML из MyAnimeList.
5. Для полного завершения используйте «Выход» в меню трея.

Личные данные сохраняются в папке data рядом с EXE. При обновлении сначала закройте приложение и сделайте копию data. В этом архиве личных данных нет.
Автозапуск включается вручную через меню трея. Настройки — по кнопке ⚙. Снимите «Показывать виджет», чтобы отключить его; настройка сохраняется.

Подробная инструкция: ../README.md. Возможности и ограничения релиза: RELEASE-NOTES.md.
