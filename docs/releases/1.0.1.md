# Anime Tracker 1.0.1

Обновление надёжности для Windows и macOS: сохранение прогресса, восстановление библиотеки и более отзывчивый поиск.

## Что изменилось

- **Надёжный +1 на Windows.** Прогресс и отмена подтверждаются после успешной записи. При ошибке прежнее значение остаётся на экране и в файле; отмену можно повторить. Тот же порядок применяется к старому диалогу редактирования/удаления.
- **Восстановление библиотеки на обеих платформах.** Загрузчик проверяет структуру XML. Валидная `.bak` восстанавливается с уведомлением; повреждённый оригинал сохраняется отдельно как `.corrupt-*`. При невозможности восстановления запись блокируется. Прежний XML и импорт MAL совместимы.
- **Поиск Avalonia.** Ввод объединяется после паузы 250 мс, последний запрос сохраняется при закрытии, строки библиотеки создаются по мере прокрутки. Плавное колёсико сохранено.
- Добавлены проверки отказа записи/восстановления и тесты списков на Windows/macOS. Win+D проверен владельцем на Windows: виджет остаётся на рабочем столе.

## Скачать и обновить

- **Windows x64:** `AnimeTracker-1.0.1-windows-x64.zip`, .NET Framework 4.8+.
- **Mac с Apple Silicon:** `AnimeTracker-1.0.1-macos-arm64.zip`, .NET включён. Метаданные допускают macOS 14, но она уже вне активной матрицы .NET 10; рекомендуемая нижняя граница проверки — macOS 15. [Инструкция Mac](https://github.com/MimicBYE/AnimeTracker/blob/v1.0.1/docs/MACOS.md).
- **Исходники:** `AnimeTracker-1.0.1-source.zip`. Контрольные суммы трёх архивов — в `SHA256SUMS.txt`.

Перед обновлением закройте приложение и сохраните резервную копию папки данных. Распакуйте новую версию отдельно; на Windows перенесите свою папку `data`, на Mac данные остаются в пользовательском Application Support. Личные библиотеки в релиз не включены. Релиз v1.0 сохранён в истории.

## Проверки и ограничения

Windows проверен вручную на отдельных данных: +1, отказ записи, перезапуск, восстановление XML, поиск/фильтры и подбор. CI проверяет общую логику на трёх ОС, Windows/macOS-пакеты, зависимости и комплект архивов. [Отчёт](https://github.com/MimicBYE/AnimeTracker/blob/v1.0.1/docs/validation/1.0.1-windows.md) перечисляет выполненные и непроверенные сценарии.

Windows EXE не подписан; Mac-пакет имеет локальную ad-hoc подпись, без Developer ID и нотарификации. Нативные Mac UI/Spaces/автозапуск, а также оставшиеся ручные сценарии Windows не объявляются проверенными этим выпуском. Каталог и расписание зависят от доступности внешних API.
