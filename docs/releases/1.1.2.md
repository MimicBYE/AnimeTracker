# Anime Tracker 1.1.2

Компактное уведомление обновления для Windows, macOS и Linux: меньше места на экране и автоматическое скрытие через 5 секунд.

## Что изменилось

- Плашка уменьшена с 420×230 до **360×160** логических единиц, текст сокращён. Кнопки **«Обновить»** и **«Напомнить позже»** остаются на одной строке в обеих темах.
- После **5 секунд** показа уведомление скрывается и откладывает эту версию на **6 часов**, как кнопка «Напомнить позже». Отсрочка сохраняется после перезапуска.
- Наведение мыши или клавиатурный фокус активного окна приостанавливают отсчёт. После ухода продолжается оставшееся время; повторное наведение не сбрасывает его.
- Сохраняются подтверждение установки, проверка SHA-256, резервные копии и откат. Отмена подтверждения ничего не скачивает. При ошибке сохранения отсрочки окно остаётся с сообщением об ошибке.

## Скачать и обновить

| Платформа | Архив |
| --- | --- |
| Windows 10/11 x64, .NET Framework 4.8+ | `AnimeTracker-1.1.2-windows-x64.zip` |
| Mac Apple Silicon, рекомендуем macOS 15+ | `AnimeTracker-1.1.2-macos-arm64.zip` |
| Ubuntu 24.04 / Mint 22.x x64, X11/XWayland | `AnimeTracker-1.1.2-linux-x64.tar.gz` |
| Исходники | `AnimeTracker-1.1.2-source.zip` |

Runtime включён в Mac/Linux; суммы четырёх архивов — в `SHA256SUMS.txt`. Личные данные и кеши в архивы не включены.

В **1.1.1** нажмите «Обновить» в уведомлении или откройте **⚙ → Обновления… → Проверить → Скачать и установить**. В 1.1.0 используйте настройки обновлений. Новый размер и таймер появятся после установки 1.1.2 и будут использоваться для следующих предложений обновления. Stable не предлагает dev без явного выбора канала.

Библиотека, статусы, серии, оценки, заметки и настройки сохраняются. Установщик оставляет резервные копии, сохраняет путь программы и существующий автозапуск. При отказе запуска/таймауте откатывает программные файлы, не перезаписывая новый прогресс старым снимком. Для 1.0/1.0.1 первый переход требует установки архива с сохранением данных. [Обновление и восстановление](https://github.com/MimicBYE/AnimeTracker/blob/v1.1.2/docs/UPDATES.md).

## Проверки и ограничения

Тесты проверяют границы кнопок, 5 секунд активного показа, паузу и остаток, настоящий таймаут WPF/Avalonia, обе кнопки/отмену, сохранение отсрочки, перезапуск и модальные окна. В отдельной Windows-копии проверены обе темы и повторный показ после сдвига тестовых часов; скачивания в ней запрещены. Core/UI запускаются на трёх ОС, Linux — под Xvfb. Публикация требует проверок пакетов и зависимостей точного релизного коммита. [Проверки функции](https://github.com/MimicBYE/AnimeTracker/blob/v1.1.2/docs/validation/2026-11-03-compact-update-notice.md), [проверки выпуска](https://github.com/MimicBYE/AnimeTracker/blob/v1.1.2/docs/validation/1.1.2-release.md).

Ручная нативная приёмка Mac/Linux, fullscreen/Spaces/нескольких мониторов не заявляется. Это окно приложения, не системный Action Center. Новый краткоживущий таймер работает только при показе плашки; постоянного опроса, служб и зависимостей не добавлено.

Windows EXE не подписан; Mac — ad-hoc без Developer ID/нотарификации (метаданные допускают 14.0, активная матрица .NET 10 начинается с 15). Linux ARM64/musl/native Wayland не входят в выпуск. Отключение питания во время замены не гарантирует автоматического восстановления. Исторические релизы сохраняются; лицензия собственного кода не выбрана.
