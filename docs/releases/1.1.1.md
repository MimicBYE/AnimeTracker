# Anime Tracker 1.1.1

Уведомления о новых версиях для Windows, macOS и Linux: обновление доступно прямо из небольшого окна приложения.

## Что нового

- **«Обновить»** открывает подтверждение перезапуска и загрузку напрямую, без перехода в настройки. Проверка SHA-256/платформы, резервные копии и откат при сбое сохранены.
- **«Напомнить позже»** откладывает эту версию на 6 часов; крестик действует так же. Отсрочка сохраняется после перезапуска, более новая версия не скрывается старой отсрочкой.
- Одно неблокирующее уведомление в текущей теме, без автоматического захвата фокуса, в том числе при скрытой библиотеке/работе через трей. Показ ждёт закрытия карточек и модальных окон; неприменённые настройки не теряются.
- Уведомления следуют настройке автопроверки и каналу stable/dev. Установка запускается только пользователем. Новых служб, таймеров опроса, зависимостей и разрешений системного центра уведомлений нет.

Дата отсрочки проверяется в существующем цикле приложения: повторный показ возможен на ближайшем цикле после 6 часов (до 15 минут). Если подтверждение установки отменено, ничего не скачивается и не устанавливается. При отказе записи отсрочки окно остаётся и сообщает причину.

## Обновление с 1.1.0

В 1.1.0 уже работает встроенный установщик: **⚙ → Обновления… → Проверить → Скачать и установить**. До установки 1.1.1 новая всплывающая подсказка ещё недоступна. После перехода следующие версии смогут предлагаться через уведомление. Стабильная сборка не предлагает dev без явного выбора.

Библиотека, статусы, серии, оценки, заметки и настройки сохраняются. Перед перезапуском создаются резервные копии; при отказе запуска/таймауте откатываются программные файлы, без записи старого снимка поверх нового прогресса. Копии не удаляются автоматически. Путь программы сохраняется, существующий автозапуск не меняется.

Для 1.0/1.0.1 и dev до AT-28 первый переход требует обычной установки архива с сохранением данных. [Инструкция и восстановление](https://github.com/MimicBYE/AnimeTracker/blob/v1.1.1/docs/UPDATES.md).

## Проверки и ограничения

Автоматические проверки уведомлений покрывают одно окно, модальный барьер, Later/крестик, сохранение/перезапуск/истечение, новую версию, отказ записи и прямое подтверждение/отмену без скачивания. Windows проверяет бинарный пакет и пересборку source ZIP; Core/UI запускаются на трёх ОС, Linux — под Xvfb. Публикация допускается только после аудита и проверки комплекта точного релизного коммита. [Отчёт AT-33](https://github.com/MimicBYE/AnimeTracker/blob/v1.1.1/docs/validation/2026-11-03-update-notices.md), [проверки 1.1.1](https://github.com/MimicBYE/AnimeTracker/blob/v1.1.1/docs/validation/1.1.1-release.md).

Это уведомление приложения, не системного Action Center. Ручная нативная приёмка фонового показа, fullscreen/Spaces/нескольких мониторов Mac/Linux ещё нужна. Windows EXE не подписан; Mac — ad-hoc без Developer ID/нотарификации, метаданные допускают 14.0, но активная матрица .NET 10 начинается с 15. Linux ARM64/musl/native Wayland не входят в выпуск. Отключение питания во время замены не гарантирует автоматического восстановления. Исторические релизы сохраняются; лицензия собственного кода не выбрана.
