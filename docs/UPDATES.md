# Обновление приложения

Начиная с AT-28: **⚙ Настройки → Обновления…**; Windows также предлагает этот пункт в трее. Используются публичные GitHub Releases проекта MimicBYE/AnimeTracker без аккаунта и API-ключа.

## Порядок обновления

Начиная с 1.1.1 (AT-33) автоматическое обнаружение версии показывает отдельное уведомление в текущей теме. Оно работает и при скрытой библиотеке/работе через трей, не забирает фокус и не блокирует основное окно.

Начиная с 1.1.2 (AT-38) плашка уменьшена до 360×160 логических единиц. Через 5 секунд показа она закрывается с той же отсрочкой на 6 часов. Наведение мыши или клавиатурный фокус активного окна приостанавливают отсчёт; после ухода продолжается оставшееся время, а не новые 5 секунд. При ошибке сохранения отсрочки окно остаётся без повторяющихся автоматических попыток. [Проверки и образцы](validation/2026-11-03-compact-update-notice.md).

- **Обновить** открывает подтверждение перезапуска и окно загрузки напрямую, без перехода в настройки. Проверка пакета, резервная копия и откат сохраняются. Отмена подтверждения ничего не скачивает и не устанавливает.
- **Напомнить позже** и крестик откладывают уведомление об этой версии на 6 часов. Номер и UTC-дата сохраняются в `update-settings.xml`; перезапуск не сбрасывает отсрочку. Повторный показ проверяется в обычном цикле (до 15 минут после срока).
- Более новая версия не скрывается отсрочкой предыдущей. Для одной версии одновременно показывается одно уведомление. После открытия установки напоминание также отложено на 6 часов, даже если установка отменена.

Открытые карточки/диалоги откладывают показ до закрытия. Несохранённые настройки не применяются автоматически. Отключение автопроверки отключает уведомления, ручной поиск обновлений остаётся доступен; stable/dev-канал соблюдается. Это окно приложения, а не системного центра: новых пакетов и разрешений ОС нет. При отказе записи отсрочки окно остаётся и показывает ошибку. [Проверки AT-33](validation/2026-11-03-update-notices.md).

1. Нажмите **Проверить**: окно показывает установленный номер, описание новой версии и результат предыдущей установки.
2. Примените или сбросьте черновик настроек приложения (оформление, виджет, автозапуск). Параметры обновлений сохраняются отдельной кнопкой **Сохранить**.
3. Нажмите **Скачать и установить**, подтвердите перезапуск. Загрузку можно отменить; ошибки загрузки, проверки и прав записи оставляют программу работающей.
4. Отдельный процесс дожидается штатного завершения приложения, создаёт копии, заменяет программу и запускает её из прежней папки. Новая версия должна подтвердить готовность за 60 секунд. При отказе запуска/таймауте установщик откатывает программные файлы и запускает прежнюю версию.

Установка всегда запускается кнопкой. Автопроверка включена по умолчанию в существующем цикле обновления серий, не чаще раза в шесть часов за сеанс. Ручная проверка доступна при отключённой автоматической; лимиты GitHub/сетевые ошибки показываются в окне.

Stable по умолчанию получает только стабильные версии; dev — также предварительные. Флажок **Получать предварительные версии** меняет канал. Его отключение не устанавливает старый stable поверх нового dev. Более свежий stable того же базового номера разрешён; номера dev сравниваются численно.

## Первый переход

В 1.0/1.0.1 и dev до AT-28 установщика нет: один раз понадобится обычная установка нового архива. В Windows завершите приложение через трей, сохраните `data` отдельно и распакуйте программные файлы в прежнюю папку, сохранив `data`. На Mac замените закрытую `.app`; данные вне пакета. На Linux сохраните XDG-папки и прежний путь программы. Следующие обновления выполняются через интерфейс.

Старые релизы не меняются. Принимаются новые пакеты с `updateProtocol: 1` в `BUILD-INFO.json`.

## Сохранение данных

- Библиотека, статусы, серии, оценки, заметки, ID и настройки остаются на прежних местах. Перед заменой создаётся снимок папок данных, включая кеш/импорты; временные файлы и блокировка экземпляра пропускаются.
- Windows заменяет только `AnimeTracker.exe`, `.config` и `BUILD-INFO.json`. Путь EXE и ярлык автозапуска сохраняются; посторонние файлы не удаляются.
- Mac подготавливает соседний пакет, сохраняет прежнюю `.app` и переименовывает пакеты. Данные внутри `.app` не поддерживаются: подготовка остановится до закрытия приложения.
- Linux заменяет перечисленные runtime-файлы с сохранением Unix-прав. Посторонние файлы остаются; откат удаляет новые файлы, которых прежде не было. Сохраняются XDG-пути, явный `--data-dir` и `--no-tray`.

Откат восстанавливает **программу**. Снимок данных не записывается автоматически поверх прогресса, который мог сохраниться после запуска новой версии. Он доступен для отдельного восстановления после проверки пользователем. Ready подтверждает запуск, а не исправность всех функций новой версии.

## Папки копий

Каждая попытка получает `update-<случайный ID>` в следующем корне:

| ОС | Корень состояния установщика |
| --- | --- |
| Windows | `%LOCALAPPDATA%\AnimeTracker.Updates` |
| Mac | `~/Library/Caches/AnimeTracker.Updates` |
| Linux | `$XDG_STATE_HOME/AnimeTracker/updates`, обычно `~/.local/state/AnimeTracker/updates` |

Внутри: архив, распакованный пакет, `plan.xml`, `result.txt`, `rollback`. Для Windows/Linux `rollback/program` содержит прежние программные файлы, `rollback/data-N` — снимки папок данных. На Mac прежняя `.app` также остаётся рядом с программой как `.previous-<ID>`. Путь копии показан в результате установки.

Автоматического удаления копий нет. После проверки новой версии завершённые попытки можно удалить при закрытом приложении; активную установку удалять нельзя. Mac Caches/Linux state не заменяют независимый backup библиотеки. Отмена может оставить папку попытки; непроверенный пакет не применяется.

## Границы

Проверяются имя/URL вложения нашего репозитория, размер/SHA-256 GitHub, архив, архитектура, версия и протокол. Ссылки, выход за корень, дубликаты и специальные записи отклоняются. На Mac выполняется `codesign --verify --deep --strict`. Пределы: архив 512 МиБ, распаковка 1 ГиБ и 20 000 записей. SHA-256 подтверждает соответствие вложению GitHub, а не отдельную подпись издателя.

Нужны права записи в папку программы. Установщик не запрашивает UAC/sudo, не меняет защиту ОС/автозапуск и не обходит Gatekeeper. Mac-пакет остаётся без Developer ID/нотарификации.

Откат покрывает обработанные ошибки записи, запуска и таймаут. Выключение питания/принудительное завершение helper во время замены не гарантируют автоматического восстановления: Windows/Linux меняют runtime по файлам с журналом и копиями. При таком сбое закройте оставшиеся процессы и используйте сохранённую программу/backup. Одновременный ручной запуск и внешнее изменение файлов во время установки не поддерживаются.

Длинные управляемые пути Framework включены в `.config`; манифест объявляет `longPathAware`. Системная политика не меняется. Регрессии проверяют backup/замену/откат на путях более 320 символов; это не обещание запуска EXE из любого пути, неподдерживаемого оболочкой Windows.
