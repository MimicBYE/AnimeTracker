Размер окна 1040×800 логических точек; время CPU/GPU, FPS, расход батареи и память процесса не измерялись. Эти результаты не устанавливают минимальную аппаратную конфигурацию и не подтверждают поведение интерфейса на Mac.

Синтетические библиотеки 1000/5000 записей: название `Тайтл 00001`, английское название, 12 серий, статус planned, без оценок, обложек и сетевых запросов. Ввод подряд `Т`, `Та`, `Тай`, `Тайт`, `Тайтл`, каждый раз с обработкой очереди dispatcher. Конструирование окна и обработчики ввода измерены до показа окна: это стоимость синхронной работы контролов/записи/перестроения, а не задержка кадра на экране. Один прогон до/после, без статистической значимости; первый вызов включает прогрев. Отложенные 250 мс и последующая фильтрация не входят в время обработчика символа.

## Проверенные сценарии

- DispatcherTimer объединяет быстрый ввод в одну запись. Повторный flush без изменений не пишет файл. Статус применяется сразу; точный поиск возвращает ожидаемую запись.
- Быстрое закрытие до отложенного `TextChanged` сохраняет текст самого контрола. Прокрутка/смена фильтра не создают все строки; null при очистке виртуального контейнера обработан.
- Общие тесты Core/AppStore: отказ записи +1 во всех пяти статусах, неизменность памяти/диска при ошибке, повторная успешная попытка и restart; отказ отмены, добавления/редактирования/удаления и восстановления удаления.
- Строгий XML: неверный root/namespace/дочерний элемент, текст вместо списка, DTD, отсутствующие поля, повторный ID, неизвестный статус. Сохранены legacy XML, пустая библиотека и необычный импортированный прогресс.
- Валидная `.bak` восстанавливается атомарно; исходник сохраняется как `.corrupt-*`, `.bak` не заменяется повреждёнными байтами. Невалидная копия и отказ восстановления оставляют файлы на месте и включают режим чтения; отсутствие основного файла при существующей копии тоже проверено.

## Воспроизведение

На Windows/macOS с SDK из `global.json` и нативным графическим окружением:

```sh
dotnet run --project tests/AnimeTracker.CoreTests -c Release
dotnet run --project tests/AnimeTracker.DesktopTests -c Release
```

DesktopTests использует временные данные, не запускает обычный App lifecycle/фоновое обновление и не открывает личную библиотеку. Для снимка синтетического списка можно передать `-- --screenshots <абсолютная-папка>`. Linux UI этой командой в CI не заявляется: там остаются Core-тесты.

Оставшиеся проверки: реальный Mac, клавиатурный ввод/IME, обложки, плавность прокрутки, холодный запуск и ресурсы на слабом устройстве; ручное восстановление при ошибках реального носителя. Требования по RAM/CPU в [SYSTEM-REQUIREMENTS.md](../SYSTEM-REQUIREMENTS.md) остаются предварительными.
