# Выпуск 1.1.1 — 3 ноября 2026

[Issue #35](https://github.com/MimicBYE/AnimeTracker/issues/35). Цель: стабильный выпуск уведомлений AT-33 и разрешённое владельцем обновление установленного Windows-приложения с сохранением данных.

Функция принята в dev [PR #34](https://github.com/MimicBYE/AnimeTracker/pull/34), merge `8b9830b`. [CI feature head 0dbd210](https://github.com/MimicBYE/AnimeTracker/actions/runs/41657246428) и Dependency review прошли полностью. Windows theme-test проверил уведомления из бинарного и пересобранного EXE; DesktopTests подтвердил Later/X, модальную отсрочку, отсутствие дубликатов и прямое подтверждение/отмену на трёх ОС.

Для 1.1.1 версия согласована set-version.ps1, текущий main включён через issue-ветку. Подготовительный PR, релизный dev → main и финальный push main имеют собственные проверки точных коммитов; результаты feature CI не заменяют их. Итоговые SHA, CI и ссылки на публикацию фиксируются в issue/PR. Опубликованные вложения проверяются по размеру/SHA-256, SHA256SUMS и provenance 1.1.1/stable/updateProtocol=1.

Регрессии используют только синтетические библиотеки, HTTP-заглушки и часы. Личные данные владельца используются отдельно только для разрешённого обновления установленной версии: резервная копия программы/данных до перезапуска, сравнение файлов и личных полей после запуска, сохранение пути/ярлыка автозапуска. Локальный отчёт обновления хранится в artifacts вне Git/релиза и не публикует личную библиотеку.

Новые ручные проверки Mac/Linux, Action Center, fullscreen/Spaces, системного DPI/мониторов, автозапуска после настоящего входа и отключения питания не заявляются. Бюджеты/зависимости прежние; [системные требования](../SYSTEM-REQUIREMENTS.md), [уведомления и backup](../UPDATES.md).
