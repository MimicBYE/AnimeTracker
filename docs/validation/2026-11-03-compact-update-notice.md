# AT-38: компактная плашка обновления

[Issue #38](https://github.com/MimicBYE/AnimeTracker/issues/38), 3 ноября 2026. Изменения после 1.1.1; рабочая установка и личная библиотека не меняются.

- Размер WPF/Avalonia — 360×160, текст сокращён, обе кнопки сохранены. UI-регрессии проверяют границы кнопок.
- Общий UpdateNoticeLifetime проверяется подменёнными монотонными часами: ровно 5 секунд, остаток при паузе, повторное наведение без сброса, продолжение до последней миллисекунды.
- WPF theme-test и DesktopTests проверяют реальный таймаут окна (5 секунд с допуском на диспетчер), сохранение Later после него, прежние кнопки/отмену без скачивания и модальный барьер. Linux — Xvfb, UI/пакеты трёх ОС — CI актуального head.
- Локально пройдены CoreTests, WPF self-test/theme-test на отдельных данных. Подготовлена отдельная IsolatedUiHost с синтетической библиотекой и условной 1.1.2; HTTP-заглушка запрещает скачивание/установку. Проверочный рендер получен из реального содержимого окна, не из рабочего стола/личной библиотеки. Внешний вид проверяется в светлой/тёмной темах.

Доказательства окончательной проверки/CI — в связанном PR. Новая ручная приёмка Mac/Linux, Spaces/fullscreen/мониторов и системного Action Center не заявляется. На рабочую 1.1.1 изменения автоматически не устанавливаются.

Образцы WPF из изолированной копии: [тёмный](../media/at-38/notification-dark.png), [светлый](../media/at-38/notification-light.png). Это рендер содержимого окна без нативной рамки, условная 1.1.2 не является объявлением настоящего релиза. Текст/кнопки визуально не обрезаны. Автозакрытие сохранило UTC-отсрочку; после перезапуска проверочная копия не показала уведомление повторно, после сдвига тестовых часов показ возобновился. Скачиваний — 0. Проверка кнопок выполнена автоматическими UI-сценариями (обе кнопки и отмена подтверждения); это не выдаётся за ручную установку.
