# AT-22 — Linux x64

28 октября 2026. База `dev` — `6e9ed02`, общее ядро AT-20. Цель — Ubuntu 24.04 x64 и совместимая Linux Mint 22.x; X11/XWayland. Личный Windows Anime Tracker не заменялся. WSL на рабочем компьютере отсутствует; Linux-проверки выполняются на GitHub runner.

## Реализация и проверяемые сценарии

- Раздельные XDG data/config/cache, абсолютные значения окружения и fallback для относительных, права новых папок 0700; перенос старого `AnimeTracker.Port` с сохранением исходника. `--data-dir` сохраняет прежний единый каталог.
- Общий backup собирает физические каталоги в логический плоский набор, включая `.bak`, кеш и импорт; исключает временные файлы и межпроцессную блокировку. При переносе в разделённые каталоги создаётся backup и выполняется rollback после ошибки. Контрактный тест принудительно блокирует запись настроек и проверяет прежний XML/память.
- Автозапуск/меню текущего пользователя, проверяемая запись `.desktop`, отмена без дублей и сохранение `--data-dir`. Нативные тесты запускают безопасный shell probe через GIO и сверяют argv с пробелами, Unicode, кавычкой, backslash, долларом, backtick и процентом. Администратор и чужие файлы автозапуска не используются.
- Основное окно открывается при `--startup` и без трея; закрытие завершает процесс. Виджет по умолчанию выключен, включаемый виджет остаётся обычным окном. Objective-C не вызывается на Linux. Трей необязателен, его ошибка не останавливает приложение.
- FileShare.None блокирует второй экземпляр до открытия библиотеки; второй запуск просит открыть существующее окно через файл запроса. Импорт не перемещает inode блокировки. Проверки используют отдельные папки.
- Linux-пакет self-contained x64. Проверяются ELF64 little-endian/e_machine x86-64, 0755, все tar entry, отсутствие symlink/path traversal/private data, обязательные файлы и совпадение BUILD-INFO. Отрицательные fixture-тесты проверяют неверную архитектуру/права/приватный XML и выход за корень tar.
- Распакованный пакет запускается под Xvfb/DBus из пути с пробелами, без трея, с отключённым сетевым таймером и искусственной библиотекой: окно/разметка, +1, статус/оценка/заметка, закрытие, перезапуск с тем же XML и второй реальный процесс. Отчёт/exit code и таймаут проверяются скриптом.
- Прежние DesktopTests запускаются и на Linux под Xvfb: 1 000/5 000 записей, виртуализация/колесо, фильтры, настройки и отмена/успех/ошибка XML-импорта. CoreTests и Windows release/source rebuild сохраняются.
- Комплект релиза содержит четыре архива с единым provenance/SHA256; `Verify release bundle` зависит от Linux package. Имена девяти прежних required checks сохранены, защита веток не меняется. Новые опубликованные stable tags/assets не перезаписываются.

Фактические результаты CI и merge фиксируются в issue #22/PR. Успешная упаковка отдельно не считается успешным нативным запуском.

## Остаётся ручная проверка

Ubuntu/Mint с GNOME/Cinnamon и KDE: отображение/отсутствие трея, вход в настоящий пользовательский сеанс с включённым автозапуском, file picker/меню оболочки, Show Desktop/рабочие столы/виджет, несколько мониторов и нативный DPI. Эти пункты остаются открытыми независимо от автоматических тестов. Ubuntu 26.04 и другие дистрибутивы, ARM64, нативный Wayland и дополнительные форматы пакетов требуют следующих этапов. AppImage/Flatpak/мобильные сборки не добавлены.
