# AT-20 — общее ядро приложения

28 октября 2026. База dev `216932d`. Все тестовые данные искусственные, личное приложение и его папка данных не изменялись. Проверяется слой приложения для существующих Windows/WPF и Avalonia; новые платформенные пакеты не добавляются.

## Изменение

Общий `TrackerService` заменил операции данных AppStore и дублированный цикл обновления Windows. Windows вызывает тот же сервис для +1/undo, карточки, статусов/оценок/заметок, добавления/удаления, импорта, настроек виджета, очереди/скрытия и арок. Пути и механизм обновления/кеша вынесены в Core. AppStore оставляет выбор системной папки и состояние модальных окон; платформенные таймеры и native API остаются в клиентах.

## Проверки

- Общие контракты `tests/Shared/TrackerServiceTests.cs` выполняются под современным .NET и .NET Framework из Windows self-test. Пять статусов, +1/отмена, completion, сохранение необычного импортированного прогресса, оценки/заметки, удаление/вставка и перезапуск.
- Отказ записи: +1/отмена/карточка/статус/заметки/добавление/удаление/MAL, очередь/скрытие, виджет и арки. До успешной записи личные поля, состав библиотеки, файл и уведомления не меняются.
- MAL commit использует текущий прогресс, сохраняет личные заметки/статус по выбранному режиму и создаёт исходный XML/копию библиотеки. Существующие 150-записные XML/GZIP/import/recovery тесты сохранены.
- Каталог заменён управляемым FakeCatalog, без сети. Проверены пакеты не более 50 ID, все пять личных статусов, правка прогресса/статуса/оценки/заметки и удаление/добавление во время запроса, отмена даже при ответе источника, игнорирование ответа после Reload/импорта/открытия модального окна, отсутствие перекрывающегося refresh, повтор после отказа записи и интервал с внедрёнными часами.
- Совместимый кеш метаданных: дедупликация/отбрасывание невалидных ID, запись/перезапуск, сохранение старой памяти при отказе записи. Кеш расписания и библиотека остаются отдельными файлами; общей транзакции между ними нет.
- Библиотеки 1 000/5 000 записей: +1, сохранение и загрузка с поэлементным сравнением всех полей.
- Windows release: C# 5 build, self-test, MAL import, содержимое архивов, сборка из извлечённых исходников и повторный self-test. Release.Tests проверяет упаковку, provenance, приватность исходников, защиту публикации и прежние артефакты.
- Avalonia на Windows: прежние автоматические проверки 1 000/5 000 записей, debounce, виртуализация, smooth wheel, фильтры, отмена выбора/предпросмотра импорта, успешный/ошибочный импорт, сохранение черновика настроек и доступность нижних действий при логических 150/200%. Используются прозрачные проверочные окна; системный DPI не меняется. Это не измерение частоты кадров.

Финальный CI и merge фиксируются в issue #20/PR. Автоматические результаты не заменяют ручной прогон нативного Mac, Win+D/жестов, трея и автозапуска после обновления этой сборкой. Проверка автозапуска AT-18 относится к предыдущей установленной сборке и не переименовывается в проверку AT-20.

## Границы

Корневая папка и XML совместимы, миграция схемы/БД не выполняется. Сервис вызывается из одного контекста хоста; конкурентные процессы, мобильные расширения и синхронизация не реализованы. Приложение владельца не заменено проверочной сборкой. Подробные правила расширения — [архитектура](../ARCHITECTURE.md).
