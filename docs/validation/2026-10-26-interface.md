# AT-13 — читаемость и приоритет действий

Дата: 26 октября 2026. База: v1.0.1 (`e0a548a`). Проверка рабочей ветки AT-13 на Windows 11 (10.0.26200), .NET SDK 10.0.403/runtime 10.0.14. Личная библиотека не использовалась. Изменения не опубликованы в стабильном v1.0.1.

## Изменения

В Windows/WPF и Avalonia главное действие выделено насыщенным жёлтым цветом и полужирным шрифтом. В подборе «Начать смотреть»/«Продолжить» или «В планы» находятся в первой строке с карточкой и другим вариантом; очередь и скрытие — ниже, без заливки.

В библиотеке название, альтернативные названия, прогресс и оценка/жанры разделены отступами. Дополнительный текст увеличен до 12 px и затемнён до #725932; статус/прогресс — 13 px основным цветом. +1 выделен, карточка спокойнее. Поиск больше не делит строку с импортом: импорт MAL расположен в настройках рядом с резервными копиями. Настройки Avalonia получили прокрутку с закреплёнными кнопками применения/закрытия; перед запуском импорта окно настроек закрывается, чтобы не оставлять два модальных окна.

## Автоматические проверки

- Windows x64: сборка штатным C# 5/.NET Framework, self-test, XML/GZIP import, упаковка и повторная сборка/самопроверка извлечённых исходников — PASS.
- Avalonia Release: сборка без предупреждений и ошибок — PASS.
- Общие CoreTests: сохранение/отказ записи/восстановление, миграция, MAL/GZIP, метаданные, обложки через заглушки — PASS.
- DesktopTests на Windows: debounce, отсутствие записи на каждый символ, фильтры, сохранение при закрытии, ограниченный viewport, виртуализация и плавное колесо — PASS.

Сеть/обложки в этой синтетической проверке отключены.

## Ручная проверка

Для WPF запущен отдельный временный IsolatedUiHost с текущей сборкой и пятью демонстрационными записями/кешем обложек. Он вызывает Tracker.Run в отдельном процессе, минуя только общий Main/mutex; исходники и штатный EXE не изменяются. Пользовательское приложение не останавливалось.

Компьютерное управление получило дерево доступности библиотеки: поиск без импорта, +1, карточки, статусы/прогресс/жанры присутствуют. Разрешение на ввод в IsolatedUiHost запрошено отдельно. Полная ручная проверка новых кликов/геометрии WPF пока не подтверждена; захват вместо целевого окна показывал Codex с запросом доступа и не принимался за изображение приложения. Нативные Mac UI/Spaces/автозапуск в этой задаче не проверялись. Оставшиеся сценарии v1.0.1 учитываются в issue #9.
