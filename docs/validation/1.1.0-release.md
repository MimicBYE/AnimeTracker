# Подготовка 1.1.0 — 3 ноября 2026

[Issue #30](https://github.com/MimicBYE/AnimeTracker/issues/30). Выпуск объединяет изменения после 1.0.1: интерфейс/импорт (AT-13/16), автозапуск (AT-18), ядро (AT-20), Linux (AT-22), темы (AT-24/26), updater (AT-28).

AT-28 принят в dev как `0eca901`; [CI исправленного head 633bf21](https://github.com/MimicBYE/AnimeTracker/actions/runs/41619734737) прошёл полностью: Core трёх ОС, desktop UI, Windows/Mac/Linux package, аудит и Verify. Windows проверил бинарный EXE и rebuild из исходного ZIP, включая реальные CLI updater-процессы. Dependency review прошёл отдельно. [Подробности updater](2026-11-03-app-updates.md).

После merge прошёл [dev CI 41620101712](https://github.com/MimicBYE/AnimeTracker/actions/runs/41620101712), опубликован неизменяемый `v1.0.1-dev.67`. Сквозная локальная проверка настоящим UpdateClient (3 ноября) выбрала его для `1.0.1-dev.62`, скачала Windows ZIP, проверила SHA-256 `20034dadc1c9f8ff77ec53a1cf91a9dc0d613d61f2a1d64a3a36d38714c98b1f`, распаковала и подтвердила платформу/версию/updateProtocol=1. Это проверка сети и подготовки на реальном опубликованном пакете, без установки/запуска. Она не заменяет проверки пакета 1.1.0.

Версия согласована скриптом set-version.ps1: VERSION, Windows assembly/manifest, Core, Desktop и Info.plist. Релизный PR и его точный head/CI — источник итоговой проверки 1.1.0; прошлый зелёный CI не заменяет проверки нового номера. Публикация стабильного тега выполняется только после отдельного принятия dev → main и успешной сборки main.

Каждый новый комплект содержит четыре архива и SHA256SUMS с matching BUILD-INFO/updateProtocol=1. Готовые файлы и их SHA-256 фиксируются в CI artifacts актуального release PR; они не считаются опубликованными вложениями stable до финального workflow.

Computer Use не применялся. Личная data и рабочая установка не менялись. Скриншоты в описании — прежние проверочные рендеры AT-24 с явно указанным происхождением; старые снимки 1.0.1 не выдаются за новый UI.

Не выполнены новые ручные проверки установки через UI, Gatekeeper/SmartScreen, Mac Spaces/автозапуска, Linux desktop login/DE, нескольких мониторов/DPI и аварийного питания. Подтверждённый ранее владельцем автозапуск Windows не означает новый logout/login-тест этой сборки. Требования и бюджеты: [SYSTEM-REQUIREMENTS.md](../SYSTEM-REQUIREMENTS.md).
