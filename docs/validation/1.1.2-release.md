# Выпуск 1.1.2 — 3 ноября 2026

[Issue #40](https://github.com/MimicBYE/AnimeTracker/issues/40). Цель: стабильный выпуск компактного уведомления AT-38 и разрешённое владельцем обновление установленного Windows-приложения с сохранением данных.

Функция принята в dev [PR #39](https://github.com/MimicBYE/AnimeTracker/pull/39), merge `15318bb`. [CI feature head cbb51cb](https://github.com/MimicBYE/AnimeTracker/actions/runs/41669316185) и Dependency review прошли полностью. WPF и Avalonia проверяют границы кнопок, настоящий 5-секундный таймаут, сохранение отсрочки, прежние кнопки/отмену без скачивания; общий таймер проверяет паузу и оставшееся время. Отдельная Windows-копия подтвердила обе темы и сохранение после перезапуска. [Подробности](2026-11-03-compact-update-notice.md).

Версия согласована set-version.ps1, история main включена через issue-ветку. Подготовительный PR, релизный dev → main и финальный push main проходят собственные проверки точных коммитов; результаты feature CI их не заменяют. Итоговые SHA, CI и публикация фиксируются в issue/PR. Опубликованные вложения проверяются по размеру/SHA-256, SHA256SUMS и provenance 1.1.2/stable/updateProtocol=1.

Регрессионные тесты используют только синтетические библиотеки и HTTP-заглушки. Личные данные владельца используются отдельно для разрешённого обновления: резервная копия программы/данных, сравнение личных полей и настроек после запуска, сохранение пути и ярлыка автозапуска. Локальный отчёт остаётся в artifacts вне Git/релиза.

Новые ручные проверки Mac/Linux, системного DPI/мониторов, автозапуска после входа и отключения питания не заявляются. Зависимости/бюджеты прежние; [требования](../SYSTEM-REQUIREMENTS.md), [порядок обновления](../UPDATES.md).
