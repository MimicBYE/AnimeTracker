# AT-16 — черновик настроек при импорте и тесный макет Avalonia

26 октября 2026. База: dev `2c31b1a`. Локально: Windows 11 (10.0.26200), .NET SDK 10.0.403/runtime 10.0.14, Avalonia 12.1.4. Только временная искусственная библиотека; личные данные и запущенная Windows/WPF-сборка не использовались и не менялись.

## Исправление

Импорт запускается из оставшегося открытым окна настроек. Это окно владеет выбором файла, предпросмотром и ошибками импорта. Выбранные оформление, включение виджета и автозапуск остаются в контролах как черновик. «Применить» — единственное действие этого сценария, которое сохраняет эти настройки; импорт их автоматически не применяет. Явное закрытие настроек по-прежнему отбрасывает неприменённый выбор.

Проверка тесного окна обнаружила дополнительный дефект PaperScroll: без StyleKeyOverride базового ScrollViewer шаблон не создавал рабочий viewport. До исправления Extent/Viewport равнялись 0; после — Extent 493 DIP, Viewport 404 DIP, нижняя позиция Offset 89 DIP. Теперь тест требует ненулевой viewport, настоящую прокрутку и плавное колесо.

## Регрессия SettingsFlowTests

Тест создаёт настоящие прозрачные окна Avalonia, вызывает реальные обработчики кнопок, читает сохранённые файлы и использует общий MAL parser/preview/merge. Подменяется только выбор пути файла: системный picker сам по себе этим тестом не проверяется. Native Windows-масштаб и macOS-интерфейс руками не проверялись.

- Отмена выбора файла: настройки остаются открытыми, черновик сохранён, библиотека и файл настроек виджета не изменены.
- Отмена предпросмотра: дочернее окно принадлежит настройкам; после закрытия остаются те же значения и корректная глубина модальных окон.
- Явный успешный импорт: новая запись переносит watching / 3 серии / оценку 7; существующая запись сохраняется, черновик настроек остаётся неприменённым.
- Неверный XML: ошибка принадлежит настройкам; после её закрытия черновик и библиотека сохранены.
- Повторный запуск блокируется, пока первое действие импорта не завершилось. После возврата кнопка доступна.
- Изменение флажка автозапуска в черновике не меняет состояние AutoStartEnabled ОС; файл настроек виджета сверяется побайтно. Тест не вызывает «Применить» и не меняет системный автозапуск.
- Закрытие настроек освобождает модальную глубину и не применяет черновик.

Локальный прогон — PASS. Существующие проверки библиотеки на 1 000/5 000 записей, debounce, фильтров, плавного колеса и виртуализации также прошли (по 4 реализованные строки).

## Масштаб и изображения

Для поверхности 1920×1080 использованы логические окна библиотеки 1280×720 и 960×540, соответствующие 150% и 200%. Настройки отдельно уменьшены до клиентской области 640×500. RenderTargetBitmap использует 144/192 DPI. Это проверка геометрии и рендера, а не измерение кадров или нативного переключения системного DPI.

Проверены границы поиска/добавления, закреплённых «Применить»/«Закрыть», доступность импорта и ZIP-копии после прокрутки. Просмотрены рендеры 200%; контрольные геометрические проверки выполняются для обоих размеров. Длинное русское и альтернативные названия включены в искусственные данные. Прокручиваемая библиотека намеренно обрезает нижнюю строку по границе viewport.
