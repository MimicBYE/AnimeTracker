# Проверка Windows перед 1.0.1

Дата: 26 октября 2026, Москва. Задача — [issue #9](https://github.com/MimicBYE/AnimeTracker/issues/9). Исходная база `7b69cc10600aaa41c6b2d03351955e2d0977ffdb`; функциональный код не менялся, метаданные синхронизированы на 1.0.1. Это отчёт подготовки, не утверждение о выпуске стабильной версии.

## Стенд и данные

Windows 11 build 26200 x64, Ryzen 5 7500F (6 ядер / 12 потоков), 31.6 ГиБ физической RAM по ОС, WPF/.NET Framework. Окно библиотеки — стандартные 900×720 логических точек. Проверялся EXE из отдельного каталога `artifacts/windows-qa-1.0.1`, без SDK-зависимости при запуске. SHA-256 проверенного интерактивно EXE: `720eae9a5a88e35182fce9cc3e2472e79b2b12334c23269e9d49d2a98a291049`. Позднейшая пересборка пакета получает собственный checksum; это тот же исходный код, не заявление о побайтовом совпадении EXE.

Использованы пять искусственных записей: Shikimori ID 52991, 50265, 33352, 57334, 11061. Названия, жанры и обложки получены из публичного каталога, статусы/прогресс/оценки/заметки заданы для демонстрации. Личная библиотека пользователя не копировалась и не попала в материалы. Обычное приложение временно остановлено и затем возвращено; системные настройки автозапуска не менялись.

Отдельная карточка аниме визуально открывается, но Computer Use не адресовал её дочерние элементы надёжно: попытки выбора статуса не засчитываются как успешный ручной сценарий. Изменение статуса через карточку, её сохранение и отмена кнопкой виджета требуют дополнительного ручного прогона. Это ограничение проверки, не зарегистрированный дефект приложения.

## Штатная диагностика и проверки сборки

- `--verify` на той же искусственной библиотеке: **PASS**. Компактный и раскрытый виджет: `attached=True`, `child=True`, `visible=True`, `minimized=False`, `aboveIcons=True`, `layered=False`. Раскрытие/сворачивание завершились; счётчик анимации — 6 кадров (не измерение FPS). Проверены геометрия и привязка всех трёх стилей; сохранены изображения реально отрисованных WPF-контролов.
- `release-windows.ps1` для 1.0.1: **PASS** self-test и XML/GZIP import-test упакованного EXE, повторная сборка из извлечённых исходников и её self-test.
- Общие проверки включают отказ записи/повтор отмены, безопасную отмену удаления, строгий/legacy XML, восстановление и режим чтения при невозможности восстановления. Это автоматические сценарии, они не подменяют непроведённые клики в карточке/виджете.
- Политика упаковки включает публичные PNG/MP4 только из `docs/media/`; пользовательские `data/covers`, временные кадры и локальный FFmpeg не распространяются.

## Что ещё проверить перед стабильным выпуском

- Карточка: смена статуса/оценки/заметки и сохранение; кнопка отмены в виджете, включая отказ записи.
- Виджет глазами на рабочем столе: Win+D, перетаскивание к краям, двойной клик и несколько мониторов. Структурная диагностика выше не подтверждает эти жесты. Автоматизация не нажимала сочетания с Windows.
- Автозапуск после настоящего выхода/входа Windows, штатный выход/возврат через трей. Сеанс пользователя не завершался, registry Run не менялся.
- Native Mac UI/Spaces/Show Desktop, автозапуск, перенос/восстановление и быстрый поиск. Windows-проверка не закрывает этот этап.

Известных новых дефектов по успешно выполненным сценариям не выявлено. Непроверенные сценарии оставлены открытыми. Стабильный v1.0 не заменён; Windows-пакет 1.0.1 подготовлен для дальнейшей проверки.
