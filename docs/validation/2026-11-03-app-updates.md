# AT-28: встроенное обновление, 3 ноября 2026

[Issue #28](https://github.com/MimicBYE/AnimeTracker/issues/28), [PR #29](https://github.com/MimicBYE/AnimeTracker/pull/29). Личная библиотека и установленное приложение не использовались для тестов и не заменялись. По просьбе владельца Computer Use не применяется.

## Автоматические проверки

- Windows C# 5 / Framework 4.8: локальные `--self-test` и `--update-process-test`. Отдельные скрытые CLI parent/helper/new process, ready, отказ запуска, timeout/rollback; без окон/регистрации ОС.
- CoreTests .NET 10: общие fixtures и настоящие CLI-процессы. Подменённый HTTP; SHA-256/размер/URL, отмена, испорченные пакеты, сохранение существующего файла назначения.
- Каналы: численный dev, явный stable → dev, запрет возврата к старому stable; новый stable того же номера после dev.
- ZIP traversal/ссылка/дубликат; TAR traversal/ссылка и Unix execute-права; архитектура/метаданные.
- Fixtures Windows/Linux/Mac: успех, отказ записи, нездоровая версия; точные личные байты/backup, посторонние файлы, удаление новых runtime-файлов при rollback.
- Длинные пути: первоначальный CI упал на File.Copy в backup. Исправлены Framework-конфигурация/манифест. Новая регрессия использует source/target/plan/backup длиннее 320 символов, проверяет версии и байты отката.
- Настройки: интервал 6 ч, опт-аут/ручная проверка, сохранение канала, отказ записи без изменения live-состояния; результат установки сохраняется после проверки.

Windows package в CI проверяет бинарный ZIP, импорт/theme-test, updater-процессы и rebuild только из source ZIP. Core запускается на Windows/Ubuntu/Mac; Linux UI/распакованный пакет — под Xvfb. Проверка четырёх архивов требует одинаковых версии/канала/коммита/протокола, отсутствия личных данных, прав исполнения и общих SHA-256. Итоговые результаты актуального head фиксируются в PR; предыдущий неуспешный запуск не считается результатом исправления.

## Что этим не подтверждено

Ручная установка через кнопки, Gatekeeper/SmartScreen, настоящий logout/login/автозапуск, разные диски, отключение питания, DPI/мониторы, ручная приёмка Mac/Linux. CLI проверяет общий процесс установки, а не весь запуск реального UI. CI/Xvfb не заменяют ручную приёмку. Рабочее приложение пользователя остаётся прежним.

Политика копий и восстановление: [UPDATES.md](../UPDATES.md). Стабильный выпуск требует успешных checks актуального release PR; исторические вложения не меняются.
