# Материалы Anime Tracker 1.0.1

Подготовлены 26 октября 2026 на Windows. Все записи искусственные; личные данные пользователя не использовались. Версия 1.0.1 готовится к выпуску, текущий стабильный v1.0 не заменён.

| Файл | Содержание и происхождение |
| --- | --- |
| [windows-library.png](windows-library.png) | Реальный кадр клиентской области WPF-библиотеки: обложки, статусы, оценки и +1 |
| [windows-evening.png](windows-evening.png) | Реальный кадр подбора на вечер из списка «В планах» |
| [windows-widget.png](windows-widget.png) | Штатный WPF-render capture настоящего виджета в стиле «Обложка с прогрессом»; не снимок всего рабочего стола и не доказательство Win+D |
| [windows-demo.mp4](windows-demo.mp4) | 20 секунд реального захвата клиентской области Windows: библиотека → +1 → подбор. H.264, около 20 fps, без звука; не benchmark |

PNG библиотеки/подбора — кадры исходной записи, без дорисовки. Видео обрезано по времени; для чётной высоты H.264 добавлена техническая строка пикселей. Виджет снят встроенной командой `--verify`. Изображения обложек и сведения о тайтлах предоставлены публичным каталогом Shikimori; права остаются у правообладателей, см. [THIRD-PARTY-NOTICES](../../THIRD-PARTY-NOTICES.md).

Заготовка подписей для GitHub Releases:

- **Библиотека:** прогресс по сериям, оценки, заметки и поиск по названиям.
- **Виджет:** компактное управление просмотром с кнопкой +1.
- **На вечер:** выбор следующего аниме из планов с фильтрами по времени и настроению.
- **Видео:** один цикл использования — отметить серию и выбрать, что смотреть дальше.

Материалы показывают Windows. Скриншоты Mac не подготовлены и ими эти изображения не являются. [Отчёт и оставшиеся проверки](../../validation/1.0.1-windows.md). Публикация стабильного релиза выполняется отдельным PR `dev → main` после оставшихся проверок.
