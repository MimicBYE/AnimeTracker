# Рендеры проверки AT-16

Созданы текущим интерфейсом Avalonia в `SettingsFlowTests`, через RenderTargetBitmap; искусственные данные, без обложек и сети. Это не снимки пользовательского рабочего стола и не нативный Mac-прогон.

150%: библиотека 1280×720 DIP, рендер 144 DPI. 200%: 960×540 DIP, рендер 192 DPI. Настройки — 640×500 DIP при обоих масштабах, прокручены до нижних действий; кнопки «Применить»/«Закрыть» остаются на месте. Черновик оформления и флажков намеренно изменён, но не применён. PNG не содержат пользовательской библиотеки. SHA-256 — в SHA256SUMS.txt.

Повторение из корня репозитория:

```powershell
dotnet run --project tests/AnimeTracker.DesktopTests -c Release -- --screenshots artifacts/ui-16/screenshots
```

Метод, проверки и ограничения: [отчёт](../../validation/2026-10-26-settings-import.md).
