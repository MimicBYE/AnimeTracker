# Anime Tracker для Linux

Первый пакет — **Linux x64**, Ubuntu 24.04 LTS и Linux Mint 22.x на её базе. Используется X11; в Wayland-сессии нужен XWayland. Другие glibc-дистрибутивы могут быть совместимы, но не считаются проверенными этим выпуском. ARM64, Alpine/musl, AppImage/Flatpak и нативный Wayland пока не входят в матрицу.

Linux-пакеты появляются в новых сборках `dev` после AT-22. Стабильный архив 1.0.1 не изменяется и Linux-пакета не содержит.

## Запуск

Скачайте `AnimeTracker-<версия>-linux-x64.tar.gz` и `SHA256SUMS.txt` из одного GitHub Release. Распакуйте весь архив файловым менеджером или командой:

```sh
tar -xzf AnimeTracker-<версия>-linux-x64.tar.gz
cd AnimeTracker-<версия>-linux-x64
./AnimeTracker
```

`<версия>` замените номером скачанного пакета. .NET runtime входит в архив; отдельная установка SDK/runtime не нужна. Не запускайте приложение через sudo. Храните распакованный пакет в постоянной пользовательской папке. Если файловый менеджер потерял право запуска, выполните `chmod +x AnimeTracker` внутри этой папки.

На обычной desktop-установке нужные системные библиотеки обычно уже есть. Для минимальной Ubuntu 24.04/Mint 22:

```sh
sudo apt update
sudo apt install libx11-6 libice6 libsm6 libfontconfig1 libxext6 libxrandr2 \
  libxcursor1 libxi6 libxrender1 libgl1 libegl1 libgtk-3-0t64 \
  libicu74 libssl3t64 zlib1g ca-certificates xdg-utils
```

Команда предназначена для указанной базы ОС: названия ICU/SSL в других версиях могут отличаться. Источники требований: [Avalonia Linux deployment](https://docs.avaloniaui.net/docs/deployment/linux), [.NET/Ubuntu](https://learn.microsoft.com/en-us/dotnet/core/install/linux-ubuntu-decision). Для Wayland-сессии пакет XWayland должен быть установлен и доступен; native Wayland backend не включается автоматически.

Основное окно доступно даже без трея. Закрытие библиотеки **завершает Linux-приложение**. Если оболочка показывает трей, из него доступны библиотека, настройки и виджет, но приложение не требует расширения GNOME для повседневной работы. `--no-tray` позволяет явно отключить трей.

## Меню приложений и автозапуск

В настройках нажмите **Добавить в меню приложений** или выполните из распакованной папки:

```sh
./AnimeTracker --install-menu
```

Ярлык создаётся только для текущего пользователя в `$XDG_DATA_HOME/applications/local.animetracker.AnimeTracker.desktop` (по умолчанию `~/.local/share/applications/`). Пакет не копируется в системные папки.

Для автозапуска включите **Запускать при входе в систему** и нажмите **Применить**. Приложение создаёт свой `.desktop` в `$XDG_CONFIG_HOME/autostart/` (обычно `~/.config/autostart/`). При входе открывается библиотека, поэтому отсутствие трея не оставляет приложение недоступным. Отключение удаляет только запись Anime Tracker. Администратор, cron и systemd-service не нужны.

Ярлыки содержат абсолютный путь к исполняемому файлу. После перемещения распакованной папки создайте ярлык заново и повторно включите автозапуск. Путь с пробелами/Unicode поддерживается; для Exec экранируются кавычки, обратная косая черта, `$`, backtick и `%`, оболочка для запуска команды не используется. Знак `=` в пути к EXE не допускается спецификацией desktop entry: выберите другую папку. [Desktop entry Exec](https://specifications.freedesktop.org/desktop-entry/latest/exec-variables.html), [autostart](https://specifications.freedesktop.org/autostart/latest/).

## Виджет

На Linux виджет **по умолчанию выключен**. Включите его в настройках при необходимости; оформление, обложка и +1 используют общие данные. Это отдельное обычное окно: его положение при Show Desktop, переключении рабочих столов и поверх других окон зависит от оконного менеджера. Закрепление за значками GNOME/KDE и сохранение видимости как у Windows не обещаются. Отключение виджета сохраняется.

## Данные и перенос

| Назначение | Путь по умолчанию |
| --- | --- |
| Библиотека, заметки, арки, личный топ, очередь/скрытия, история импорта | `~/.local/share/AnimeTracker/` |
| Фильтры, сортировка, настройки/положение виджета | `~/.config/AnimeTracker/` |
| Обложки, отметки серий, расписание и кеш каталога | `~/.cache/AnimeTracker/` |
| Ошибка запуска | `~/.local/state/AnimeTracker/startup-error.txt` |

Абсолютные `XDG_DATA_HOME`, `XDG_CONFIG_HOME`, `XDG_CACHE_HOME` и `XDG_STATE_HOME` учитываются. Пустые/относительные значения заменяются стандартными. Новые корневые папки приложения создаются с правами 0700; существующие права не меняются. [XDG Base Directory](https://specifications.freedesktop.org/basedir/latest/).

Если использовался прежний Avalonia fallback `AnimeTracker.Port`, при пустом новом хранилище валидные данные копируются в XDG-каталоги. Исходная папка сохраняется. При наличии одновременно старых и новых данных автоматического объединения нет: используйте перенос через настройки. Ошибка не приводит к удалению старой библиотеки.

Для переноса с Windows/macOS выберите папку с `library.xml` в настройках. Поддерживаются прежние XML и личные поля. Перед заменой создаётся отдельная папка резервной копии. При отказе записи в разделённые каталоги выполняется восстановление предыдущих файлов; если и восстановление не удалось, ошибка указывает папку копии. Исходный выбранный каталог остаётся на месте.

**Резервная копия ZIP** собирает data/config/cache в совместимый плоский набор: `library.xml`, `widget-settings.xml`, `covers/` и остальные файлы. ZIP нельзя сохранять внутрь этих трёх папок. Автозапуск и абсолютные пути ярлыков не переносятся. Одновременная запись двумя экземплярами предотвращается блокировкой; второй обычный запуск просит уже работающий процесс открыть библиотеку.

Для отдельной переносимой/проверочной библиотеки:

```sh
./AnimeTracker --data-dir "/полный/путь/к/отдельной-папке"
```

В этом режиме все файлы остаются в указанной папке, автоматического переноса fallback нет. Если из такого запуска включить автозапуск или установить меню, путь `--data-dir` сохраняется в ярлыке.

## Сборка и границы проверки

Для разработки нужны SDK из `global.json` и PowerShell 7.4+ для упаковки:

```sh
pwsh -File scripts/build-linux.ps1
```

Проверка архива и запуск распакованного приложения с искусственными данными:

```sh
xvfb-run -a -s '-screen 0 1920x1080x24' dbus-run-session -- \
  pwsh -File scripts/build-linux.ps1 -SmokeTest
```

CI проверяет ELF x86-64, режим 0755, весь tar, provenance, приватность, запуск/закрытие без трея, +1/статус/оценку/заметку, перезапуск, второй экземпляр и прежние сценарии Avalonia. Реальный parser GIO отдельно проверяет argv ярлыка на сложных путях. Xvfb не подтверждает поведение GNOME/KDE, реальный вход/автозапуск, несколько мониторов, системный DPI или расход памяти на пользовательском устройстве. [Отчёт AT-22](validation/2026-10-28-linux.md).
