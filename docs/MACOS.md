# Anime Tracker для Mac · 1.0

Версия на Avalonia для Apple Silicon и macOS 14+. Библиотека, каталог, заметки, календарь, топы, арки, подбор на вечер и XML/GZIP-импорт используют общую логику с Windows. Интерфейс на русском. .NET включён в архив, отдельно устанавливать runtime не нужно.

## Запуск

Распакуйте `AnimeTracker-1.0-macos-arm64.zip`. Входная точка — **Anime Tracker.app**; переместите приложение в Applications. Папка Contents содержит внутренние файлы, запускать отдельные DLL не нужно.

Сборка с Windows подготовлена для проверки на Mac. Она не подписана сертификатом Developer ID и не нотарифицирована Apple; Gatekeeper может блокировать её запуск. Для локальной разработки предусмотрена сборка из исходников на самом Mac с локальной ad-hoc подписью. Публичный подписанный релиз потребует сертификата владельца проекта и нотарификации.

## Перенос библиотеки с Windows

1. Закройте Windows-приложение через трей и скопируйте его папку `data` на Mac целиком.
2. Откройте шестерёнку справа сверху → **Перенести папку из Windows**.
3. Выберите скопированную папку `data` и проверьте число записей перед подтверждением.

Сохраняются ID, статусы, просмотренные серии, оценки, заметки, фильтры, скрытые рекомендации, очередь, арки и кеш обложек. Исходная папка не изменяется. Прежние данные Mac сохраняются рядом отдельной папкой `AnimeTracker.before-import-*`.

Данные Mac находятся в `~/Library/Application Support/AnimeTracker`. Через настройки можно открыть эту папку и экспортировать резервную копию ZIP. XML-форматы совместимы с Windows; перед обратным переносом закройте обе версии и сохраните резервную копию. Положение виджета Mac хранится отдельно от координат Windows.

## Виджет и автозапуск

В настройках снимите **Показывать виджет** и нажмите **Применить**, чтобы пользоваться только приложением. Выбор сохраняется после перезапуска. Кнопка **Виджет** включает его снова. Закрытие библиотеки оставляет приложение в строке меню; **Выход** завершает его полностью.

Автозапуск включается вручную в настройках после переноса `.app` в Applications. Используется пользовательский LaunchAgent `~/Library/LaunchAgents/local.animetracker.desktop.plist`; включение/отключение действует при следующем входе. При перемещении приложения обновите настройку.

Виджет реализован отдельным окном macOS с уровнем рабочего стола и поддержкой Spaces. Реальное поведение с Show Desktop, Mission Control, несколькими дисплеями и автозапуском **ещё нужно проверить на Mac**. Проверки интерфейса Avalonia под Windows не подтверждают эти функции macOS.

## Сборка на Mac

Установите официальный .NET SDK 10 для arm64. Из папки проекта выполните:

```sh
sh scripts/build-macos.sh
```

Скрипт создаёт `.app`, применяет локальную ad-hoc подпись и проверяет её через `codesign`. Путь к результату выводится в терминале; архив находится в `dist/macos`. Это локальная сборка для разработки, без Developer ID и нотарификации.

Для кросс-сборки из Windows с SDK 10:

```powershell
.\scripts\build-macos.ps1
```

Архив сохраняет Unix-права запуска. Исходники расположены в `src/AnimeTracker.Desktop`, общая логика — в `src/AnimeTracker.Core`. Личные данные в архивы не включаются.

## Проверка на Mac

Проверить первый запуск и повторное открытие из Dock/строки меню; перенос библиотеки и сохранность прогресса; поиск и загрузку обложек; отключение виджета после перезапуска; Show Desktop и Spaces; автозапуск после повторного входа.
