# Подготовка папки для GitHub

Из корня проекта в Windows PowerShell выполните:

```powershell
.\scripts\prepare-github.ps1
```

Скрипт собирает и проверяет Windows-релиз, берёт уже подготовленный Mac-архив и создаёт **новую** папку `AnimeTracker-GitHub` рядом с проектом. Существующая папка не перезаписывается; для повторной подготовки укажите другой путь:

```powershell
.\scripts\prepare-github.ps1 -OutputDirectory ..\AnimeTracker-GitHub-next
```

Если Mac-архив отсутствует, сначала выполните `scripts/build-macos.ps1` с установленным SDK .NET 10. Для упаковки уже проверенного Windows-релиза предусмотрен параметр `-SkipWindowsBuild`.

## Что находится внутри

- `repository/` — корень будущего GitHub-репозитория: README, исходники обеих платформ, тесты, скрипты и документация. Личная библиотека, EXE, SDK, кеши и промежуточные сборки сюда не копируются.
- `releases/windows-v1.0.2/` — переносимый Windows ZIP, архив исходников, контрольные суммы и описание стабильного релиза.
- `releases/macos-v1.1.0-alpha.1/` — Mac ZIP для Apple Silicon, контрольные суммы и описание предварительного релиза.
- `releases/SHA256SUMS.txt` — общие контрольные суммы ZIP-файлов.
- `START_HERE.md` — краткая инструкция по содержимому папки.
- `verification.json` — результат проверки состава файлов, ссылок документации и архивов.

Версии в именах папок берутся из `VERSION` и проекта `AnimeTracker.Desktop`; приведённые выше номера соответствуют текущей подготовленной версии.

## Публикация

Содержимое `repository/` предназначено для исходного репозитория. Соседняя папка `releases/` предназначена для вложений GitHub Releases и не должна попадать в исходный репозиторий. Скрипт не создаёт удалённый репозиторий, не отправляет коммиты и не публикует релизы.

Windows `v1.0.2` и macOS `v1.1.0-alpha.1` подготовлены как отдельные релизы. Для Mac нужно сохранить отметку **Pre-release**: запуск на реальном Mac, Spaces, Show Desktop и автозапуск ещё не проверены. Подпись Developer ID и нотарификация отсутствуют.

Лицензия собственного кода пока не выбрана. Файлы атрибуции и лицензии сторонних компонентов сохраняются в `docs/` и Mac-пакете; они не определяют лицензию всего проекта.
